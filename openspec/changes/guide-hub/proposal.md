## Why

Currently lack a centralized hub for technical guides and knowledge. This would improve knowledge sharing and onboarding for users unfamiliar with the portfolio's technical aspects and provide some useful guides.

## What Changes

- Add "Guides" navigation button to footer and navbar
- Create GuideHub component listing all available guides
- Implement Markdown rendering for guide content
- Add routing for guide-specific pages

## Capabilities

### New Capabilities
- `guide-display`: Renders Markdown files as HTML with proper syntax highlighting

### Modified Capabilities
- No existing capabilities require requirement changes

## Impact

- Affects: Footer navigation, navbar, GuideHub component, Markdown rendering service, routing configuration
- Minimal impact on existing pages
- No breaking changes
